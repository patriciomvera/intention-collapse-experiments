# Intention Collapse Paper

## Description
Research paper proposing "Intention Collapse" - intention-level metrics for evaluating reasoning in LLMs. Distinguishes between internal intention formation and its "collapse" into verbalization.

## Current Status
- Version 2 published on arXiv
- Preparing version 3 for EMNLP 2026 or ACL 2026

## Project Structure
- `/docs/paper` - LaTeX files synced with Overleaf and current paper PDF
- `/notebooks/pilot` - First notebook from the experiment in paper v1
- `/notebooks/scaled` - Current paper notebooks
- `/results` - Currently unused (results stored in Google Drive)
- `/src` - Core experiment code
